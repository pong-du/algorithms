# 황혼의 딕싯 (Dixit)

폰 하나로 돌려가며 즐기는 모바일 딕싯 게임입니다. 서버·설치 없이 `index.html` 파일 하나로 동작합니다.

## 플레이 방법

- `index.html`을 모바일 브라우저에서 열면 바로 시작할 수 있습니다.
- 3~6명이 폰 한 대를 돌려가며 플레이하는 pass-and-play 방식입니다.
- 84장의 카드는 시드 기반으로 절차 생성된 SVG 일러스트라 별도 이미지 파일이 필요 없습니다.

## 규칙 (기본 딕싯 규칙)

1. 매 라운드 이야기꾼이 카드 한 장을 골라 힌트를 냅니다.
2. 다른 플레이어도 힌트에 어울리는 카드를 한 장씩 냅니다.
3. 카드를 섞어 공개하고, 이야기꾼을 제외한 전원이 이야기꾼의 카드에 투표합니다.
4. 전원 정답 또는 전원 오답이면 이야기꾼 0점, 나머지 +2점. 그 외에는 이야기꾼과 정답자 +3점.
5. 자기 카드가 받은 표 하나당 +1점. 30점에 먼저 도달하면 승리합니다.

## 기능

- 모바일 우선 반응형 UI, 터치 친화적 카드 확대 프리뷰
- 진행 상황 자동 저장(localStorage) — 새로고침해도 이어하기 가능
- 오프라인 동작 (웹폰트만 온라인에서 로드, 폴백 폰트 내장)
