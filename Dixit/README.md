# 황혼의 딕싯 (Dixit)

모바일 딕싯 게임입니다. 두 가지 버전이 있습니다.

- `index.html` — **패스 앤 플레이**: 폰 하나를 돌려가며 플레이. 서버·설치 없이 파일 하나로 동작합니다.
- `online.html` — **온라인 멀티플레이**: 각자 폰으로 접속해 방 코드로 함께 플레이. Claude 아티팩트의 `db` 런타임(실시간 공유 문서 저장소)을 사용하므로 아티팩트로 게시된 링크에서만 온라인 기능이 동작합니다.

## 온라인 버전 구조

- 게임 상태는 `rooms/<코드>` 문서 하나에 저장하고, 카드 제출·투표는 플레이어별 문서(`subs/<pid>`, `votes/<pid>`)로 분리해 동시 쓰기 충돌을 피합니다.
- 전원 제출/투표가 모이면 아무 클라이언트나 문서 lease(`acquire`)를 잡고 단계를 전환합니다. 호스트가 나가도 게임이 멈추지 않습니다.
- 새로고침해도 같은 방으로 자동 재입장하며, 진행 중인 방에 늦게 들어오면 관전 모드가 됩니다.

## 플레이 방법

- `index.html`을 모바일 브라우저에서 열면 바로 시작할 수 있습니다.
- 3~6명이 폰 한 대를 돌려가며 플레이하는 pass-and-play 방식입니다.
- 카드 84장은 AI로 생성한 몽환풍 일러스트 시트를 잘라 데이터 URI로 내장했습니다 (외부 이미지 요청 없음).

## 규칙 (기본 딕싯 규칙)

1. 매 라운드 이야기꾼이 카드 한 장을 골라 힌트를 냅니다.
2. 다른 플레이어도 힌트에 어울리는 카드를 한 장씩 냅니다.
3. 카드를 섞어 공개하고, 이야기꾼을 제외한 전원이 이야기꾼의 카드에 투표합니다.
4. 전원 정답 또는 전원 오답이면 이야기꾼 0점, 나머지 +2점. 그 외에는 이야기꾼과 정답자 +3점.
5. 자기 카드가 받은 표 하나당 +1점. 30점에 먼저 도달하면 승리합니다.

## 기능

- 모바일 우선 반응형 UI, 터치 친화적 카드 확대 프리뷰
- 진행 상황 자동 저장(localStorage) — 새로고침해도 이어하기 가능
- 오프라인 동작 (웹폰트만 온라인에서 로드, 폴백 폰트 내장)
